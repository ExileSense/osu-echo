API v2

Fills in the profile below (picture, banner, bio, details; click Save changes afterwards) adds their best scores and first place ranks (no replays), and, if ticked, looks up your official leaderboard rank on each of your top 100 plays (shown in the game's leaderboard; this is the slow part). Needs your own osu! OAuth client in .data/osu_oauth.json. Takes about a minute, or a few minutes with the leaderboard lookup, because requests are paced for osu!'s rate limit. Safe to repeat.
